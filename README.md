# Vergia Brown Portfolio

A responsive portfolio site built with React, TypeScript, and Vite. Its opening power button starts an animated system-loading sequence before revealing a dismissible Brown OS 99 welcome window inside a vintage CRT monitor. The light-mode monitor has a hyper-realistic warm plastic casing and physical CRT details around a playful pixel-inspired desktop UI and surreal pink rolling-hills wallpaper; dark mode keeps its neon, starry landscape and original CRT finish. The site uses a custom disco-ball cursor based on the supplied reference, with a text cursor preserved in editable fields. Home, About Me, Projects, Creative, Community, and Connect are represented by clickable, topic-specific icons, and the monitor taskbar includes a client-side search that finds matching content across all six pages. The light website background uses a soft, dot-free pastel sky inspired by the visual references, with a scrapbook-like scattering of cloud and disco-ball illustrations outside the monitor. It also includes a creative project gallery with category filters, a contact page with a prefilled email form, a dedicated Wavco section, a light/dark theme toggle, and expandable hackathon case studies.

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local development URL when the server starts. Create a production build with `npm run build`.

## Personalize

Replace the bracketed prompts and starter gallery concepts in `src/App.tsx` with Vergia's biography, work history, education, hackathon entries, Wavco events, creative work, and project details. Update the social profile URLs in the Connect page when available. The contact form opens the visitor's email app with a draft addressed to vividcreations.vergia@gmail.com; visitors must send the draft from that app. The starter skills are examples and should be replaced with skills Vergia wants to highlight.
